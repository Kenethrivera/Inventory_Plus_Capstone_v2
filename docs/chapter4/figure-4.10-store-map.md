Figure 4.10 shows the Inventory Plus admin Store map interface in three views. (1) The selected navigation item opens the Store map page. (2) The layout tools let the administrator select and place doors, racks, shelves, cashier areas, and walls. (3) The floor plan displays the store layout and its fixtures on a grid. (4) The fixture panel provides controls for moving and resizing a selected fixture. (5) The Discard and Save map buttons revert or save layout changes. (6) Assign items mode enables product placement on racks or shelves. (7) The map shows the fixtures where selected products can be assigned. (8) The Items to place panel shows assignment progress and the product list. (9) The search and filters help find unassigned or assigned products. (10) The 3D view option displays the store layout as a three-dimensional model. (11) The model shows the placement of walls, doors, shelves, racks, and the cashier area. (12) The side panel lists products assigned to the selected shelf.
