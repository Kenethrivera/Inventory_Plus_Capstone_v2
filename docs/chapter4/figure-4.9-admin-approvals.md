Figure 4.9 shows the Inventory Plus admin Approvals interface. (1) The selected navigation item opens the Approvals page. (2) The status tabs separate pending, approved, and rejected requests. (3) The type and time filters narrow the request list. (4) The request list shows submitted restock and write-off requests. (5) The selected request displays the requester, date, request type, and product. (6) The stock summary shows the quantity on hand, the proposed change, and the resulting quantity. (7) The supporting image provides visual evidence for the request. (8) The note field allows the administrator to enter a reason when rejecting a request. (9) The decision buttons allow the administrator to reject or approve the selected write-off request.
